# 2026.269.0814 — docs(kindcluster): remove the duplicate kind skill entity

## Summary of changes

Remove `candy/plugin-kube`'s `kind` skill entity: the skill (family `kubernetes`)
is owned by `opencharly/layer-kind` — the repo of the `kind` candy the skill
documents. plugin-kube's copy was added in plugin-kube#7 as a stopgap while
`layer-kind` had no `main`; now that `layer-kind` is a proper org member, the
entity belongs there.

generate` that resolved BOTH would write one corpus path
(`kubernetes/skills/kind/SKILL.md`) twice. The companion PR on `layer-kind`
enriches that repo's entity with the substrate content folded from here; this PR
deletes the duplicate. One skill, one owner.
